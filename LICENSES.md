## Rules
- New code in core repos: Apache-2.0 + SPDX headers.
- MIT repos stay MIT; they are not relicensed by implication.
- Proprietary/experimental repos are marked as such and excluded from OSS claims.
- Models: see the model card; base-model licenses apply.
