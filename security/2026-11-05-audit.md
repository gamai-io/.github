# gamAI trust layer — internal security audit (2026-11-05)

> **Status:** internal, third-party-style review. **This is not an independent external audit.** It uses automated scanners plus manual code review. A true independent audit requires an external firm and a scoped engagement.

## Scope

| Repo | Version / commit | In scope |
|---|---|---|
| `proofgate-runtime` | 0.1.0 / `c0b2695` | claims, receipts, guard, MCP, CLI |
| `sigil` | 0.22.1 / `d6bd40c` | gate, verify, anchor, MCP middleware |
| `gamai-trust` | 0.3.1 / `402a9f6` | proofgate, immunity, crossnode |
| `gnp-trust` | `5770cc6` | node token gate, leases, exec |
| `gama-sandbox` | `eab9a58` | srt/bwrap isolation |
| `floor-copilot` | `d9d5cd2` | invoice API, evidence gate |
| `gama-fastpath` | `8799ed8` | pre-LLM gate, cache, math |

Out of scope: the other 21 repos, frontend/browser code, live penetration testing, cloud/IAM configuration, and the LUMI cluster itself.

## Method
- **Bandit 1.9.4** (Python SAST) over the seven repos.
- **pip-audit 2.10.1** against `floor-copilot/requirements.txt`.
- **Secret scan** (regex: GitHub PATs, AWS keys, private keys, `sk-`, Google API keys).
- **Manual review** of auth gates, receipt verification, subprocess use, path handling, Docker hardening.
- **CI** status checked after fixes.

## Findings

| ID | Severity | Finding | Status |
|---|---|---|---|
| AUD-01 | High | `floor-copilot` pinned Pillow 11.3.0 (6 CVEs) and Starlette 0.46.2 (multiple CVEs via FastAPI 0.115). | **Fixed** in `d9d5cd2`: FastAPI 0.162.0, Starlette 1.10.0, Pillow 13.0.0, httpx 0.28.1, python-multipart 0.0.33, uvicorn 0.54.0, numpy 2.4.6. `pip-audit`: **No known vulnerabilities**. 7 tests + health 200. |
| AUD-02 | High | `gnp-trust` used SHA1 for task IDs (Bandit B324). | **Fixed** in `5770cc6`: `usedforsecurity=False`; IDs stay stable. |
| AUD-03 | High (accepted) | `crossnode-bench` uses `subprocess(..., shell=True)` to execute benchmark tasks. | Accepted: commands are fixed in `TASKS`, nodes are operator-controlled, no untrusted input. Run in a disposable environment. |
| AUD-04 | High (accepted) | `gnp-trust` `/exec` uses `shell=True`. | Accepted by design: token/action tier required, sanitized env, no `exec` exposed by the `gnp-trust` MCP wrapper. |
| AUD-05 | Medium (accepted) | `proofgate-runtime` accepts unsigned receipts by default (`require_signature=False`); MCP `make_receipt` is unsigned. | Documented in README/SECURITY. Recommend `--require-signature` in production; default should flip in v0.2. |
| AUD-06 | Medium (accepted) | Several services bind `0.0.0.0` (SIGIL gate/verify/anchor/kms, GNP node, fastpath). | SIGIL runs in containers with an internal network + TLS edge; GNP is loopback-bound in systemd; fastpath is firewalled (verified externally: 8071 unreachable). Recommend explicit bind + firewall for new deployments. |
| AUD-07 | Medium (false positive / test-only) | Bandit B608 in SIGIL `gate.py` (`DELETE FROM {t}`). | Table names come from a fixed tuple and the endpoint requires `SIGIL_TEST=1`. No user input. |
| AUD-08 | Low (accepted) | Bandit B108/B310 (temp paths, `urlopen` schemes) in tests/bench and internal HC calls. | Bench/test code; no untrusted scheme input in the reviewed paths. |
| AUD-09 | Info | Secret scan over the seven repos. | **No secret patterns found.** |
| AUD-10 | Info (positive) | Controls verified. | HMAC `compare_digest`, fail-closed claims/receipts, Docker `read_only` + `cap_drop: ALL` + `no-new-privileges` + non-root for SIGIL; token gates on GNP; CI green after fixes. |

## Bandit summary
- Initial run: 121 findings — 4 HIGH, 57 MEDIUM, 60 LOW (most are temp paths and test code).
- After AUD-02: GNP has 1 HIGH (`B602` shell=True, accepted), 6 MEDIUM, 4 LOW.
- No HIGH finding indicates untrusted input reaching a shell in the reviewed code paths.

## Limitations
- Internal review, not an independent external audit.
- Static analysis only; no dynamic penetration test.
- Only seven repos reviewed; no DAST, no cloud/IAM review, no SBOM/container scan.
- `sigil` dependencies were reviewed via its pyproject but not separately pip-audited in this pass.
- Findings are point-in-time; dependencies and code change.

## Recommended next steps
1. **P0 (done):** patched dependencies, SHA1 non-security use.
2. **P1:** add a CI security job (`bandit`, `pip-audit`, secret scan) to every repo; enable Dependabot.
3. **P1:** `proofgate-runtime` v0.2 — default `require_signature=True`, documented key handling; consider signing MCP receipts via an env key.
4. **P2:** external independent audit + penetration test for `sigil`/`gnp`/`proofgate-runtime`; publish scope and results.
5. **P2:** explicit bind addresses + rate limits for exposed services; container/SBOM scan in CI.
